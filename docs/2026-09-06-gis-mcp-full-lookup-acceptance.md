# GIS MCP 전체 공부 조회 확장

## 정본과 변경 범위

2026-09-06 사용자 요청: 명부 작성·대조에 활용하도록 GIS 인스펙터의 14개
조회 항목을 공간정보 MCP에서 모두 요청할 수 있게 한다. 기존 5개 도구는 유지하고
`lookup_full_gis_public_data_v1`을 추가한다.

사용자는 같은 세션에서 `buldHoCoList`의 별도 이용허락을 확보했다고 명시했다.
이 작업은 그 허락에 따른 통하리 배포의 연동이며 일반 공개 이용조건이 변경됐다는
의미가 아니다. 기존 2026-09-03 acceptance의 해당 endpoint 제외 규칙은 이
전체 조회 도구에 한해 갱신한다. 비밀·소유자 개인정보·원문 오류 비노출과
MCP 서버 자체가 DB·cache에 쓰지 않는 계약은 유지한다.

2026-09-08 사용자 요청으로 소비자 대상 결과 저장 금지 경고·지시는 제거한다.
최신 계약은 `2026-09-08-gis-mcp-storage-instructions-acceptance.md`를 따른다.
원천 서비스의 이용조건 및 자료별 이용허락은 이번 내부 지시 변경과 별개다.

공식 조건 확인: https://www.data.go.kr/data/15140366/openapi.do
데이터 의미 정본: Obsidian `통하리-GIS-API-인스펙터`, `통하리-공공-GIS-MCP`.

## 역할과 실행 순서

1. 기획·분석: 14개 source와 명부 대조 필드·출처를 대응한다.
2. 구현: 독립 조회 client/projection, 전체 조회 orchestration, MCP 계약을 나눈다.
3. 리뷰: 면적·호실·지분 의미, 페이지 완전성, PNU 일치, 비밀 비노출을 검토한다.
4. 검증: fixture 테스트, 기존 MCP 회귀·전체 테스트·빌드, 운영 배포와 실호출을 확인한다.

## 반환 의미

부분 필지 포함 면적이나 사람별 소유지분을 공개 공부 수치로 자동 덮어쓰지 않는다.
전체 조회는 자료 수집 기능이며 명부 생성·DB 반영은 별도 작업이다. 원자료의
갱신일과 조회일을 구분하고, 페이지가 남으면 전량 수집 완료로 표시하지 않는다.


## 검증 기록

- TypeScript build, property-building writer guard 통과.
- 최신 main을 반영한 `npm test`: 1,567 pass, 0 fail, 4 skip (총 1,571).
- 새 client fixture는 건축물대장 숫자 PK, 공급자 중복 원본행, 명시적 개별주택 0건 대체 envelope, API 오류, 페이지 반복·불일치·취소를 포함한다.
- 미아동 749-4에서 **로컬 MCP 핸들러 → 실제 14개 공급자 호출**: 약 3.1초, 핸들러 오류 0, source SUCCESS 12 / NO_DATA 2. 다음 페이지도 약 3.3초에 같은 14개 상태로 정상 반환했다.
- 테스트는 각 source 2행 window였다. 전유부·층별개요·가격·대지권은 다음 페이지가 있어 전체 응답은 PARTIAL이며 전량 반환 완료로 표기하지 않았다.
- 공시가격의 공급자 중복 원본행은 삭제하지 않고 DUPLICATE_SOURCE_ROWS 경고로 보존했다.
- 공급자 결과·키를 파일이나 DB에 저장하지 않았다. 이 문서는 호출 상태와 검증 집계만 기록한다.
- 운영 endpoint 배포 검증은 로컬 핸들러의 공급자 실호출과 별도다. 병렬로 진행되던 토지면적 런타임 작업 종료와 승인 상태를 확인한 뒤 배포한다.
