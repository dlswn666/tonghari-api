# GIS MCP 결과 저장 금지 지시 제거

## 정본과 변경 범위

2026-09-08 사용자 요청: GIS MCP가 자체적으로 부가한 결과 저장 금지 조건을 제거한다.
이 요청은 기존 공개 GIS MCP 정책의 소비자 대상 저장 금지 문언을 대체한다.
서버가 조회 결과를 DB/queue/cache에 직접 쓰지 않는 구조와 소비자가 결과를
별도 저장 경로로 사용하는 행위를 구분한다.

이번 작업은 MCP가 제공하는 경고·지시·설명의 정정이다. 공급기관 약관이나
자료별 이용허락을 변경하지 않으며, 모든 자료의 이용이 무조건 허용된다고 선언하지 않는다.
새 DB writer, 인증·권한 확대, 공급자 변경, 수집 데이터 변경은 포함하지 않는다.

## 역할과 순서

1. 기획/분석: 주 에이전트가 사용자 요청과 이전 계약의 변경점을 확정한다.
2. 검증 설계: 독립 에이전트가 기존 코드에서 실패하는 계약 회귀 테스트를 먼저 추가한다.
3. 구현: 다른 에이전트가 runtime 문언과 고정 경고만 수정한다. 주 에이전트는 문서를 정정한다.
4. 리뷰: 구현자와 분리된 검토자가 누락 지시, 계약 호환성과 보안 경계를 확인한다.
5. 검증/배포: 전체 테스트·TypeScript 빌드·writer guard, 최신 main 병합 재검증,
   main merge/push, 기존 GHCR→EC2 배포와 실제 MCP 응답을 각각 확인한다.

      소비자 대상 결과 저장 금지 지시가 남지 않는다.
- [x] A3 지오코딩/전체 조회 설명은 서버 자신의 read-only 동작과 소비자의 후속 저장을 혼동하지 않는다.
- [x] A4 대체 문구로 무조건 저장 허용을 선언하거나, 표현만 바꾼 일괄 금지를 신설하지 않는다.
- [x] B1 6개 도구의 이름·입력·결과 데이터·상태·pagination·출처는 유지된다.

- [x] C1 이전 문서의 소비자 대상 금지 문언을 이번 요청으로 정정하고 서버 비저장 설계는 유지한다.
- [x] C2 회귀 테스트 RED→GREEN, 전체 테스트, 빌드, writer guard와 독립 리뷰를 통과한다.
- [ ] D1 최신 main을 작업 브랜치에 반영한 동일 후보를 main에 merge/push한다.
- [ ] D2 배포 SHA와 실제 MCP 응답의 경고 제거를 확인한다. 클라이언트의 이전 도구 설명 캐시는 별도로 보고한다.

- `npm run build`, `node scripts/check-property-building-link-writers.mjs`, `git diff --check` 통과.

  독립 리뷰 환경의 프로토콜 검증은 loopback listen 권한으로 취소됐으나,
  포트 허용 환경의 위 32건 및 전체 테스트에서 통과를 확인했다.
- 위 A/B/C는 소스·로컬 실행 확인이며, D1/D2는 별도 배포 증거로 확정한다.

이 작업은 상계주공10단지 데이터 입력의 선행 수정이다. 구역 생성이나 공공 데이터
적재를 수행한 것으로 보고하지 않는다. 운영 DB 데이터 변경은 없다.
