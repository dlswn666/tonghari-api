# 법령 MCP 응답 파싱 오류 복구

## 요구사항과 정본

사용자 요청: 지역별 과소필지 검토를 막는 법령 MCP 오류부터 수정한다.
정본은 `docs/2026-08-31-current-law-legal-mcp-acceptance.md`와 Obsidian `Projects/도시정비법-분석-MCP.md`다.
운영은 `https://api.tonghari.kr/mcp`, `tonghari-api/src/services/legal-research`의 research → render 계약이다.

## 역할과 실행 순서

1. 기획/분석: 최소 질문으로 실패 단계를 분리하고 실제 공급자 응답을 확인한다.
2. 구현: 실응답의 재현 테스트를 먼저 추가하고 확인된 형식 차이만 처리한다.
3. 리뷰: 현행성·관할·출처 식별 검증이 느슨해지지 않는지 독립 검토한다.
4. 검증: 파서·provider 회귀, 전체 테스트·빌드, 공식 GitHub 배포, 실제 MCP research → render를 확인한다.

- [x] 인증값과 개인정보가 없는 최소 재현 fixture 및 회귀 테스트로 실패를 입증한다.
- [ ] 정상 현행 법령·서울 과소필지 조례 조회가 원문과 출처 식별자를 보존해 반환된다.
- [x] 잘못된 형식·다른 출처·현행이 아닌 근거를 기존과 같이 거부한다.
- [ ] 공개 도구 계약 및 research packet → render 검증을 유지한다.
- [x] 필요한 진단 정보는 고정 단계/필드 등으로 제한하고 OC·URL 인증값·원문·질문을 로그에 노출하지 않는다.
- [x] 관련 테스트, 전체 API 테스트, TypeScript 빌드와 writer guard가 통과한다.
- [ ] 최신 main을 반영한 후보를 공식 배포 workflow로 운영에 반영하고 health의 소스 SHA와 기존 MCP 인증 상태를 확인한다.
- [ ] 실패하던 실제 MCP 질문을 재호출하고 research와 render 결과를 확인한다.

## 범위

이번 작업은 법령 MCP 조회 복구다. 지역별 과소필지 필터 확장과 소유 원장 변경은 별도다.
근거 부족에 따른 정상적인 결론 유보는 성공적인 조회와 구분하여 보고한다.

## 확인된 원인과 수정

- EC2 고정 IP 진단 Actions `34926003764`, `34926142663`: 조례 검색은 HTTP 200/6건, 상세도 HTTP 200이나 파서의 식별정보 누락 검사에서 `SCHEMA_DRIFT`.
- 실제 상세는 `LawService > 자치법규기본정보`, `조문 > 조[]`(104개), 나란한 배열의 부칙(32개), 루트 `별표단위[]`(13개)였다.
- 조례 분기에서만 확인된 기본정보·조문 노드를 추가한다. 부칙 날짜·번호·본문은 동일 인덱스로 보존하고 배열 길이·타입이 다르면 거부한다.
- 기존 국가 법령 구조, 요청 MST/ID 검증, 관할·현행성 검증, 공개 MCP 계약을 유지한다.
- 테스트 fixture는 실측 구조와 공개 식별정보를 사용하며 본문은 합성 값이다. 공급자 원문을 복사한 fixture로 표현하지 않는다.
- 수정 전 신규 provider 회귀 테스트에서 `SCHEMA_DRIFT`를 확인했다. 수정 후 전체 API 테스트 1,680개: 1,676 pass, 4 skip, 0 fail.
- 1차 배포 뒤 parser probe는 검색·상세와 104개 조문/32개 부칙/13개 별표를 정상 처리했다. 동일 MCP 질문에서는 제2조 지정 선택이 실패해 추가 조사했다.
- 조문 제한을 제거한 MCP 반환은 본문 `제2조(정의)`를 `제200조`로 표시했다(제4조→제400조, 제6조→제600조도 확인). 공급자 복합 번호의 선행 0 여부는 이 반환에서 확인되지 않아 테스트는 두 폭을 합성 변형으로 검증한다.
- 조례에 한해 번호 코드와 본문 선두 표제를 대조해 일반 번호 또는 `조 번호 * 100 + 가지번호`가 일치할 때만 정규화한다. 별도 가지번호 모순은 거부하며 본문 중간 참조·비조문·국가법령은 변환하지 않는다.
- 최종 전체 API 테스트 1,701개: 1,697 pass, 4 skip, 0 fail. TypeScript 빌드와 writer guard 통과.
